Overview

This window lists all elements (excluding duplicates) in the grid column to be filtered. For cells without values, the synonym  [empty cells]  is inserted as the first list element. The filter is defined by checking the items; only checked items are displayed in the grid after the filter window is passed. The filter window can be moved with the mouse like a normal window.

If the list contains only a few elements that can all be displayed in the filter window, the checks can be made directly:

▪As an alternative to a direct mouse click, the status of the checkboxes can also be changed using the space bar for the currently selected list item.

▪You can also set the check status of all active items by moving the mouse cursor vertically downwards in the left half of the listbox while holding down the left mouse button. Moving the mouse cursor upwards cancels the check status.

▪Double-clicking in the right half of the listbox negates the current status of all active items.

This approach is impractical for large lists that cannot be displayed completely in the filter window. In this case, masks for automatically check list elements can be defined in a separate context menu window (accessible via right-click).

If a subset of checkboxes is checked, the display can be grouped by double-clicking in the first panel of the status bar; this means that all checked items are displayed at the top of the list. Double-clicking again removes the grouping; after automatic marking through the context menu window, grouping is done automatically.

Notice

▪The filter can only be passed with the button Apply if at least one element and not all elements are checked.

 

▪The number of rows filtered in the grid may differ from the number of entries marked in the filter, since the filter list does not contains duplicate items, which are of course included in the grid.
