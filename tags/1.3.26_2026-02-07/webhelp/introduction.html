GExperts Version 1.3.25 (Updated 2024-08-24)

 

GExperts is a free set of tools built to increase the productivity of Delphi and C++Builder programmers by adding several features to the IDE. GExperts is developed as Open Source software and encourages user contributions to the project.

 

GExperts would not exist without the help and advice of many people. For more credits see the change log and commit history, or open the GExperts about box. Please take a moment to read the GExperts License Agreement.  Also, remember that the Readme.txt file included with GExperts will often contain information not included in this help file, including the latest changes, known bugs, and plans for the future.

 

The latest version of GExperts and the FAQ are always available at: https://gexperts.dummzeuch.de. You can send bug reports and suggestions using the Feedback Wizard in the GExperts about box.

 

For other GExperts related queries use the GExperts sub-forum in Delphi Praxis at
