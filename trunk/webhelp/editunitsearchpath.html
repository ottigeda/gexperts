Overview

The "Edit Unit Search Path" expert helps you editing the current project's unit search path.

Notice

▪

The expert offers the same functionality as the "IDE Enhancement for search paths" (see Configuration, IDE Enhancements).

 

▪

The "IDE Enhancement for search paths" should work in all Delphi versions from Delphi 6 and later.

 

▪

This expert is only available in Delphi versions from Delphi 2009 and later because the OTAPI did not offer access to the target list in earlier versions.

 

Details

 

 

The dialog offers the following functionalities ...

▪Multi line editing

▪Make relative / absolute for the currently selected line(s)

▪Prepend .. / Remove .. for the currently selected line(s)

▪Move current line up or down with the arrow buttons or Ctrl + up/down arrow keys

▪Favorites menu for currently used paths (if items available, open popup for selecting item in the other case open the favorites form directly)

▪A simple way to select the target for which to edit the path

Notice

▪

The preselection of a specific target can be set in the configuration. This dialog is not accessible in the expert itself, but only in the GExperts configuration.
