Overview

TOP

The "Uses Clause Manager" allows you to manage both uses clauses of the current unit. The used units are shown in the left part of the experts window. There you can delete units from these lists or move entries from one of the lists to the other. However, main task will be add units for new commands or declarations added in your source.

Although it is possible to drop files from Windows Explorer onto both uses lists, the required units are usually determined in the lists placed in the right part of the expert window and copied from there into the uses lists.

The check mark Add fast (to interface) or Add fast (to implementation) is available for all lists and will automatically add the selected unit to the uses clause given in the caption and close the dialog. Which uses clause is given in the caption depends on where the cursor in the edit window was located. If it was in the interface section, the caption will say "to interface", if it was in the implementation section, the caption will say "to implementation".

The Open Unit button does the obvious: It opens the selected unit in the code editor and closes the dialog. Note that there is a shortcut Ctrl+O for it, or you can just double click an entry. In this case the unit names in the source are not changed.

The OK button closes the dialog and commits your changes, the Cancel button or Escape closes the dialog and discards any changes.

Notice

▪

The Uses Clause Manager does not sort the units in the source, nor does it detect or remove unused units.

 

Used units (left part of window)

TOP

 

Available actions   |▲|

On the left of the experts window there are two lists with the units in the Interface and Implementation uses clauses respectively. The four buttons below these lists Delete from these lists or Move entries from one of the lists to the other.

New required units are usually determined in the lists placed in the right part of the expert window and added from there into the uses lists; further information can be found in the next paragraph. Alternatively, you can drag files from the Windows Explorer to any of these two lists to add a unit.

In addition to drag and drop from the available units lists it's now also possible to drag and drop entries between the two uses lists.

Below the two lists there are also buttons to Add Unit Prefixes or Remove Unit Prefixes (name space qualifiers), e.g. they convert "Registry" to "System.Win.Registry" and vice versa. This functionality is helpful for people who develop software for multiple Delphi versions including those ancient versions that did not support name spaces.

Notice

▪

Adding these prefixes is a bit tricky because the experts needs to go through all the configured name spaces in the project and use the unit search path to find a unit matching these name spaces. If it does not find them, it will not change the unit name.

 

▪

Although the two lists are initially sorted, added or moved items are currently unfortunately placed at the end of the lists.

 

▪

Dragging also works from left to right by removing entries from Uses lists. But note that only the list on the Favorites page accept entries! Unfortunately, the drag cursor is not set to No Drop over the first three lists and the unit will be removed from the source list even though it is not inserted in the destination list.

 

Context menu and keyboard shortcuts   |▲|

All Buttons also have corresponding context menu items and keyboard shortcuts:

▪Delete - Always deletes from the currently focused list. This is also the default action executed with a double click (actually it has always been the default action).

▪Move - Moves selected item from the current list to the other.

▪Open Unit - Opens the currently selected unit in the editor and closes the dialog.

▪Add to Favorites - Adds the currently selected unit(s) to the favorite units list and opens the favorites tab.

▪Unalias - Will replace units like WinTypes and WinProcs which have been declared as aliases to Windows for ages with their actual unit. The same goes for dbiTypes, dbiProcs and dbiErrs which will be replaced with BDE.

 

Available units (right part of window)

TOP

On the right of the experts window there are five pages with lists from which the desired unit can be selected and added to the uses lists in the left part of the experts window. Except the list of the Favorites page all lists were filled automatically; the content of the Favorites list must be determined by the user.

 

Pages "Search path" + "Project" + "RTL/VCL"   |▲|

Search Path list contains all units in the current unit search path. Project list shows all units of the current project. The VCL/RTL list holds all units of VCL/RTL. The caption is a bit of a misnomer, because the list also contains units from the Firemonkey framework.

With the filter above the lists you can narrow down the listed entries, e.g. entering "vcl" will only show items that contain that string in the unit name. The list is updated dynamically, so changing the filter will immediately show different entries. While the focus in on the filter edit, you can not scroll the list (in contrast to the identifiers list).

The buttons in the Add to.. group box should be self explanatory. They add the selected unit(s) to the uses clause in the interface and implementation section respectively. Note that both buttons have two keyboard shortcuts: Alt+C/Alt+L adds the selected unit(s) and keeps the expert open, Ctrl+C/Ctrl+L adds the selected unit(s) and automatically closes the expert.

The lists offers multiple selection and dragging selected unit(s) to the Interface or Implementation unit lists on the left.

With the button Add all to favorites you can copy all list elements to the Favorites list; the current selection is not taken into account. Favorites should represent a manageable and exclusive selection, so all elements of a list should only be included in exceptional cases - even if the number of visible items can be reduced by the filter.

All Pages have corresponding context menu items and keyboard shortcuts:

▪Add to Implementation - Adds the currently selected unit(s) to the implementation list.

▪Add to Interface - Adds the currently selected unit(s) to the interface list.

▪Open Unit - Opens the currently selected unit in the editor and closes the dialog.

▪Add to Favorites - Adds the currently selected unit(s) to the favorite units list and opens the favorites tab (see above notes).

On the Project page, you will also find the Copy/Save List button, which allows you to copy the entire list to the clipboard for later use. Directly next to it is an arrow button that opens the following context menu:

▪Copy .. to clipboard - Copies the complete list to the clipboard for later use.

▪Save .. to disk - Opens the save file dialog to save the complete list to any file.

 

Page "Favorites"   |▲|

The list placed at the Favorite page is a list of the users favorite units. It is recommended to limit list items to a manageable number of elements - even if the number of visible items can be reduced by the filter. Initially this list is empty, the content can be captured either via file dialog, by copying elements from other lists, dragging from the Used lists or the Windows Explorer.

With the filter above the list you can narrow down the listed entries, e.g. entering "vcl" will only show items that contain that string in the unit name. The list is updated dynamically, so changing the filter will immediately show different entries. While the focus in on the filter edit, you can not scroll the list (in contrast to the identifiers list).

The buttons in the Add to.. group box should be self explanatory. They add the selected unit(s) to the uses clause in the interface and implementation section respectively. Note that both buttons have two keyboard shortcuts: Alt+C/Alt+L adds the selected unit(s) and keeps the expert open, Ctrl+C/Ctrl+L adds the selected unit(s) and automatically closes the expert.

The list offers multiple selection and dragging selected unit(s) to the Interface or Implementation unit lists on the left.

With the button Add Unit.. you can add any unit via file dialog to the favorites list, the button Delete Unit deletes the currently selected units(s) of the favorites list. The list will only be re-sorted alphabetically the next time the program is started.

The Favorites page has corresponding context menu items and keyboard shortcuts:

▪Add to Implementation - Adds the currently selected unit(s) to the implementation list.

▪Add to Interface - Adds the currently selected unit(s) to the interface list.

▪Open Unit - Opens the currently selected unit in the editor and closes the dialog.

▪Add Unit - Opens the file dialog and let you add any unit file to the favorites list.

▪Delete Unit - Removes the currently selected unit(s) from the favorites list.

 

Page "Identifiers"   |▲|

The last list, placed at the Identifiers page, is probably the most useful one. It lists all identifiers and units from the units search path, the list items are sorted alphabetically by identifier in the first column.

With the filter above the list you can narrow down the listed entries, e.g. if you type "TWinControl" the list will be filtered down to less than 10 items of several thousand entries. The list is updated dynamically, so changing the filter will immediately show different entries. Even while the focus in on the filter edit, you can scroll the list (in contrast to all other lists). Below the list there are three buttons that control the way the filter works, these buttons actually can get the input focus, so they can be pressed using the keyboard:

▪Start - Show items that start with the search string.

▪Anywhere - Show items that contain the search string.

▪Start First - Show items that start with the search string first, followed by others that contain the search string.

The buttons in the Add to.. group box should be self explanatory. They add the selected unit(s) to the uses clause in the interface and implementation section respectively. Note that both buttons have two keyboard shortcuts: Alt+C/Alt+L adds the selected unit(s) and keeps the expert open, Ctrl+C/Ctrl+L adds the selected unit(s) and automatically closes the expert.

Unlike the other pages, there is no multiple selection available and no dragging to the Interface or Implementation unit lists on the left.

The Identifiers page has corresponding context menu items and keyboard shortcuts:

▪Add to Implementation - Adds the currently selected unit to the implementation list.

▪Add to Interface - Adds the currently selected unit to the interface list.

▪Open Unit - Opens the currently selected unit in the editor and closes the dialog.

▪Add to Favorites - Adds the currently selected unit to the favorite units list and opens the favorites tab.

▪Copy this Identifier.. - Copies the selected identifier to the clipboard for later use and keeps the expert open.

▪Search this.. - Opens your default browser and starts an internet search for currently selected identifier.

Notice

▪

The Identifier page can be used as a complete replacement of the Find Unit refactoring of the Delphi IDE (which for me doesn't work most of the time and if it does is very slow). And of course the Uses Clause Manager also works for older Delphi versions which simply didn't have this refactoring feature.

▪

If you  filter for TWinControl and the expert found several matching entries, the two top ones in the unit Controls. While this looks like a bug at first, but in fact - it's no bug, it's a feature. There are actually two declarations of TWinControl in the unit Controls (forward declaration and class declaration) The expert lists them both, when the user opens the file the cursor will be placed in the line of the associated declaration.

▪

The Identifiers list is updated in a background thread. For this to work it parses all source files in the various search paths of the project. And because this takes a while, it caches the results and only updates this cache if a new unit is found or a unit has been changed. The directory for this cache is configured in the GExperts Configuration dialog on the General page.

 

Statusbar

TOP

The status bar always shows the full path of the selected unit in the 1st panel; the second panel shows the files line number of the currently selected identifiers declaration (for Page "Identifiers" only). Right clicking on the status bar shows a context menu with the following menu items:

▪Copy this text.. - Copies the full file name to the clipboard.

▪Copy this file.. - Copies the file to the clipboard so it can be used as if copied from the Explorer.

▪Open location.. - Opens the folder in which the file is located in the Explorer and selects the file.
